# Simple Calculator Using Streamlit

A beginner-friendly calculator web application built using Python and Streamlit. The application performs basic arithmetic operations through a simple and interactive web interface.

## About the Project

This project demonstrates how Python can be used with Streamlit to create a basic web application. Users can enter two numbers and view the results of four arithmetic operations.

It is one of my beginner projects as I continue learning Python and web application development.

##  Features

- Addition of two numbers
- Subtraction of two numbers
- Multiplication of two numbers
- Division of two numbers
- Interactive number input fields
- Simple and user-friendly interface

## Technologies Used

- **Python** — Programming language
- **Streamlit** — Web application framework
- **Pandas, NumPy, Matplotlib** — Imported in the current code but not yet used in the calculator's functionality
